# Xiaomi MJSXJ05CM / IPC019: безопасное исследование

Дата: 2026-09-22. Камера: `192.168.1.53`, MAC `xx:xx:xx:xx:xx:xx`, версия `4.3.9_0445` по данным владельца; с устройства её напрямую не считывали.

Главный результат: **0/65535 открытых TCP-портов**. Локальный RTSP/ONVIF/HTTP не найден. [STATUS.md](STATUS.md) отделяет факты от предположений и указывает следующий шаг.

| Каталог | Содержимое |
|---|---|
| `network/` | ping/ARP, TCP scans, HTTP/RTSP/SSDP/WS-Discovery/miIO пробы |

| `research/` | источники, оценка downgrade, будущий локальный стек |
| `scripts/` | локальные read-only анализаторы и discovery probe |
| `logs/` | попытка пассивного capture; pcap не получен из-за прав/топологии |

Никакие образы или scripts записи не запускались на камере. Публичный `downgraded_firmware.bin` из чужого SPI dump не скачивался и не предназначен для этой камеры.
